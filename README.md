# Project Hub

개인 프로젝트 현황·할 일·일정을 한 곳에서 관리하는 정적 웹사이트 (빌드 없음, GitHub Pages).

- **개요**: 프로젝트 카드(상태·배포·링크·열린 할 일) + 요약 지표(열린 할 일 / 기한 지남 / 7일 내 마감 / 막힘)
- **보드**: 할 일 · 진행 중 · 막힘 · 완료 칸반. 드래그로 상태 변경, 프로젝트별 필터, 칸 하단 `+ 추가`로 빠른 입력
- **일정**: 마감일 기준 타임라인 (기한 지남 / 7일 내 / 30일 내 / 이후)

## 데이터 저장
- 기본: 브라우저 `localStorage` (`project_hub_v1`). 우측 상단 `⋯` → JSON 백업 다운로드/불러오기.
- 기기 간 동기화(선택): 배지를 눌러 **동기화 코드**를 입력하면 모든 기기가 Supabase(`flowcraft_sync` 테이블, 행 id `hub:<코드>`)를 통해 동기화됩니다.
  - 항목(프로젝트·할 일)별로 `updatedAt`이 최신인 쪽이 이김, 삭제는 툼스톤으로 전파, 동시 쓰기는 `updated_at` 조건부 PATCH로 감지 후 재시도.
  - 코드를 아는 사람은 데이터를 읽고 쓸 수 있으니 추측하기 어려운 코드를 쓰세요. 민감 정보(키·비밀번호)는 적지 마세요.

## 구조
```
index.html   레이아웃
style.css    디자인 토큰(다크/라이트) + 컴포넌트
app.js       상태·렌더링·편집·드래그·동기화 (초기 데이터 seed() 포함)
```
